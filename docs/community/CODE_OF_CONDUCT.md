# Code of Conduct

## Our Standard

We are committed to a welcoming, respectful, and technically constructive project.
Communicate with empathy, assume good faith, give actionable feedback, and respect
different backgrounds and levels of experience.

Unacceptable behavior includes harassment, discrimination, threats, personal attacks,
sexualized language, publishing private information, and deliberate disruption of
project collaboration.

## Enforcement

Report unacceptable behavior through a private GitHub channel with the relevant link,
context, and safely shareable evidence. Reports are reviewed fairly and confidentially
where practical. This policy is adapted from the
[Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
