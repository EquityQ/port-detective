## Language policy / 文档语言策略

User-facing documentation in this directory provides English first and a Chinese
section or direct language counterpart. Code comments remain English; CLI output and
examples may be localized where the product supports it. Repository operating files
such as `AGENTS.md` and `PROGRESS.md` remain controlled project records and may use the
language required by the development workflow.

本目录面向用户的文档均提供英文内容和中文内容或对应语言入口。代码注释统一使用英文；CLI 输出和示例可根据产品功能进行本地化。`AGENTS.md` 与 `PROGRESS.md` 属于项目协作控制文件，按开发流程要求维护，不作为普通用户文档处理。
